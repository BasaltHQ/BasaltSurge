# Shop Setup

## Overview

Shop Setup is the reference guide for establishing a merchant experience.

## Walkthrough

- Claim your shop slug: Choose the public identifier customers use to find your shop.
- Add your inventory: Prepare the catalog before sharing the storefront.
- Share your shop: Use the public shop link once the storefront is ready.
- Create orders: Use orders or terminal payments for the appropriate selling workflow.

## Takeaway

Use the manual as a checklist for merchant setup.
