# Withdrawal

## Overview

Withdrawal explains the documented funds-release workflow.

## Walkthrough

- Money flow: Understand how payments reach the split contract and wallet.
- Release funds: Locate the actual release workflow before taking action.
- Before cashing out: Review the checks described in the withdrawal guide.
- Exchange deposit: Verify asset, network and destination before transferring.
- Bank withdrawal: Use the receiving provider’s withdrawal workflow after the deposit is available.

## Takeaway

Know where to check the withdrawal procedure.
