# Partner Administrator Manual (BasaltSurge)

Welcome to the **BasaltSurge Partner Administrator Manual**. This guide is designed for white-label platform partners to manage their merchant networks, customize brand aesthetics, set up fee structures, provision physical devices, and monitor compliance.

---

## Partner Role & Capabilities

As a Partner, your administrator wallet gives you control over the tenant container space. You act as the coordinator between the platform operators and the merchants onboarding under your brand:

1. **Brand Identity Control**: Define logos, favicon assets, and CSS theme variables.
2. **Merchant Operations**: Review applications, configure payment splits, and review network volume report aggregates.
3. **Touchpoint Provisioning**: Set up handheld or desktop terminals, configure lockdown levels, and manage device security PINs.
4. **Modules & Studio Plugins**: Activate or disable tabs in the merchant sidebar to customize their console.
